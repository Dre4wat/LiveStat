# LiveStat Arena v0.7

LiveStat is a cinematic black, red and white sports alert app for NFL, NBA, college football, men's college basketball and women's college basketball.

**Features:** Select Sport → Select Game → Select Player → Alert Loadout. Watch individual stat changes, set once-per-game target milestones, and receive Web Push notifications when supported.

The full app uses Node.js 20+, a live-data adapter, and a monitoring server. GitHub Pages **cannot** run its Node.js background server. Live ESPN feeds and iPhone push delivery require real-world validation.

The secure demo is designed to require **no private access code**. Anonymous sessions isolate saved alerts per browser.

Source import is in progress. Keep secrets, session data, environment files and VAPID keys outside version control.
